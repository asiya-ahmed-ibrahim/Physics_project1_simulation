# Heat Engine Efficiency Simulator 🔬

Interactive physics simulation demonstrating heat engine efficiency calculations. Built for a physics class assignment.

## About

A visual tool to understand how temperature affects heat engine efficiency. Adjust temperature parameters and see real-time efficiency calculations. Includes interactive simulation machine visualization.

## Features

- 🌡️ **Temperature Adjustment System** - Interactive sliders to modify hot and cold reservoir temperatures
- ⚙️ **Simulation Machine** - Visual representation of the heat engine with real-time operation
- 📊 **Real-time Efficiency Calculations** - Instant computation of engine efficiency based on temperature inputs
- 📈 **Visual Display** - Clear visualization of efficiency values, temperature ratios, and engine performance
- 🎨 **Interactive UI** - Responsive design with smooth animations
- 📱 **Mobile Friendly** - Works on all devices

## How It Works

The simulator uses the Carnot efficiency formula:
```
η = 1 - (T_cold / T_hot)
```

Where:
- T_cold = Cold reservoir temperature (Kelvin)
- T_hot = Hot reservoir temperature (Kelvin)
- η = Theoretical maximum efficiency

Adjust the temperature sliders to see how the heat engine simulation machine responds and efficiency changes dynamically.
